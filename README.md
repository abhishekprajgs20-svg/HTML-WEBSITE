# HTML Pages Viewer Repository

This is a ready-to-deploy repository to host multiple HTML files for free on Vercel or Render.

## How to add new HTML files?
1. Open the `public/pages/` folder in this repository.
2. Upload your new HTML files inside this folder (e.g., `07-Oct-2026.html`, `25-Sept-2026.html`).
3. Commit and push the changes to GitHub.
4. The website will automatically update and display the new files on the homepage!

## Deployment

### Deploying to Render (Free)
1. Go to [Render.com](https://render.com/).
2. Create a new **Web Service**.
3. Connect your GitHub repository.
4. Render will automatically detect Node.js. Use `npm start` as the start command.
5. Deploy!

### Deploying to Vercel (Free)
1. Go to [Vercel.com](https://vercel.com/).
2. Click **Add New Project**.
3. Import your GitHub repository.
4. The `vercel.json` file is already included, so Vercel will know how to host the app automatically.
5. Click **Deploy**.
